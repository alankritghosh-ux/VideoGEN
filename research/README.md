# Venture-opportunity research (October 2026)

Question: what can a small, software-first company in Bengaluru build today that customers will pay for, that can be validated with accessible evidence, and that becomes more valuable as it operates?

Start with `venture-opportunity/executive-decision.md`. It stands alone.

## Deliverables (`venture-opportunity/`)
| File | What it is |
|---|---|
| `executive-decision.md` | Decision memo: recommendation, ranked opportunities, evidence, risks, next action, 7/30/90-day gates |
| `competitive-landscape.csv` (+ `-gaps.md`) | 70-company competitor database with layer, buyer, data, pricing, adoption, defensibility, sources |
| `opportunity-scorecard.csv` (+ `-method.md`) | 16 hypotheses, criteria, weights, pre/post-red-team scores, uncertainty, final rank |
| `research-ledger.csv` | 431 material claims with URL, date, evidence class, uncertainty, decision informed |
| `data-source-catalog.csv` | 108 datasets/APIs with access status, cost, licence, granularity, restrictions, relevance |
| `technical-validation-plan.md` | Architecture, prototype scope, baselines, metrics, experiments, thresholds, costs, limitations |
| `commercial-model.xlsx` (+ `-summary.md`) | Editable assumptions, scenarios, unit economics, 10/100/1,000-customer cases, sensitivity |
| `red-team-review.md` | Hostile review, counter-evidence, updated ranking, unresolved risks |
| `30-day-execution-plan.md` | Day-by-day first week, weekly plan, budget, gates, stop conditions |
| `quality-control-checklist.md` | Independent audit of the checklist items and mechanical checks |

## Evidence base (`research_notes/Venture scale opportunity search/`)
Fourteen research notes (global and Indian EO companies, energy software and Indian forecasting regulation, Indian electricity data sources, physical-world use cases, outside-thesis opportunities, commoditization evidence, solar forecasting feasibility, F1 customers, F2/F3 commercial facts, two red-team notes) plus `decision_brief.md`, the coordinator's synthesis that fixes the ranking every deliverable follows.

Evidence classes used throughout: Verified fact / Independently corroborated / Estimate / Hypothesis / Unknown. Access date for all sources: 2026-10-17. No experiments were run and no customer has been contacted; everything here is desk research.
